
## Evidencias del caso de estudio

### Evidencia 1. Catálogo oficial de NASA
Se consultó el NASA Exoplanet Archive para
identificar el catálogo de exoplanetas confirmados
que servirá como referencia para el proyecto.

https://exoplanetarchive.ipac.caltech.edu/

### Evidencia 2. Documentación de la API TAP
Se revisó la documentación oficial del servicio
TAP para conocer el mecanismo de consulta y
extracción de información mediante ADQL.

https://exoplanetarchive.ipac.caltech.edu/docs/TAP/usingTAP.html

### Evidencia 3. Diccionario de variables
Se identificaron las principales columnas del
catálogo y sus respectivas descripciones, unidades
y tipos de información.

https://exoplanetarchive.ipac.caltech.edu/docs/API_PS_columns.html


### Evidencia 4. Dataset de exoplanetas
Se realizó una consulta al catálogo Planetary
Systems y se obtuvo información en formato CSV,
que será utilizada como fuente de archivos.

https://exoplanetarchive.ipac.caltech.edu/TAP/sync?query=select+*+from+ps&format=csv
